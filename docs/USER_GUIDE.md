## 3 分钟快速开始

1. 从 [最新稳定版 Release](https://github.com/Aspeternity/Asterun/releases/latest) 下载与你系统架构对应的 ZIP。
2. 把 ZIP **完整解压**到一个长期使用、可写的目录，例如 `D:\Tools\Asterun`。
3. 运行 `Asterun.exe`。
4. 按 **Alt + Space** 呼出启动器。
5. 直接输入程序名、快捷词或路径的一部分。
6. 用 **↑ / ↓** 或 **Tab** 选择结果，按 **Enter** 启动。
7. 按 **Esc** 隐藏启动器。

Asterun 默认使用 **Modern Compact（现代紧凑）** 界面，默认界面语言为简体中文。运行时设置、快捷项、使用记录和搜索缓存保存在程序目录旁的 `data/` 中。

第一次使用时，不需要先配置一大堆选项。建议先正常搜索和启动几次常用程序，等熟悉基本操作后，再按需要开启 Everything、自定义快捷项或调整快捷键。

## 最常用的键盘操作

Asterun 的核心思路是：**呼出以后尽量不用鼠标。**

| 操作 | 默认按键 | 说明 |
| --- | --- | --- |
| 呼出 Asterun | **Alt + Space** | 全局快捷键 |
| 打开快捷项管理 | **Alt + S** | 全局快捷键 |
| 上 / 下一项 | **↑ / ↓** | 结果列表循环选择 |
| 下一项 / 上一项 | **Tab / Shift + Tab** | 适合左手连续操作 |
| 执行当前结果 | **Enter** | 启动程序、打开文件或执行快捷项 |
| 快速执行编号结果 | **1–9 / 0** | 1–9 对应第 1–9 项，0 对应第 10 项 |
| 打开设置 | **F2** | 启动器打开时可用 |
| 在文件管理器中定位 | **Ctrl + Enter** | 适用于可定位的结果 |
| 复制选中目标 | **Ctrl + Shift + C** | 复制目标文本/路径 |
| 隐藏启动器 | **Esc** | 不退出后台程序 |

这些动作可以在 **设置 → 快捷键** 中修改。全局快捷键与启动器内快捷键是分开的：前者在 Asterun 后台运行时也能触发，后者只在启动器窗口中生效。

如果某个全局快捷键被 PowerToys、输入法、其他 Launcher 等程序占用，Asterun 会提示热键冲突，但不会因此强制退出。进入 **设置 → 快捷键** 改成其他组合即可。

## 搜索技巧与智能排序

Asterun 不要求你完整输入程序名。搜索框可以直接输入：

- 程序名称的一部分；
- 自定义快捷词；
- 中文、拼音或拼音首字母；
- 英文首字母或模糊片段；
- 路径片段；
- 开启 Everything 后的文件名和文件夹名。

例如 TeamSpeak 不一定要完整输入 `TeamSpeak`，平时习惯输入 `team` 或 `ts` 都可以。中文程序开启 **启用拼音搜索** 后，也可以用拼音习惯进行查找。

Asterun 还会把你的**使用频率和最近使用情况**作为排序信号。也就是说，如果某个查询下你经常选择同一个结果，它会逐渐更靠前。正常使用即可，不需要手动维护“常用程序排行榜”。

如果你想重新开始学习记录，可以进入 **设置 → 数据 → 清除使用历史**。

如果某个刚安装或刚移动的程序没有及时出现，可以使用 **设置 → 数据 → 重新建立程序索引**。

## 智能数字键快速执行

这是 Asterun 比较有特色、也最容易第一次让人疑惑的功能。

开启 **设置 → 常规 → 搜索与执行 → 数字键快速执行结果** 后，结果右侧会按顺序对应：

`1 2 3 4 5 6 7 8 9 0`

其中 **0 表示第 10 项**。

通常情况下，看到目标排在第 2 项，直接按 `2` 就可以快速执行，不必先按 ↓ 再按 Enter。

但 Asterun 不会把所有数字都粗暴地当成“结果编号”。它会判断这个数字更像是在**继续输入**，还是更像在**执行结果**。

例如你想搜索：

`v2rayN`

已经输入 `v` 后继续按 `2`，Asterun 会检查 `v2` 是否存在明显的搜索延续。如果 `2` 更像是程序名的一部分，就会把它作为文本继续输入，而不是误执行第二项。

因此你可能会发现：

- 有时按数字会立即启动对应结果；
- 有时数字会正常进入搜索框；
- 在 Everything 动态结果仍在确认时，Asterun 可能短暂等待后再决定。

这不是随机行为，而是为了减少“程序名里带数字却误启动结果”的情况。

如果你完全不需要这个功能，可以在 **设置 → 常规** 关闭 **数字键快速执行结果**，数字键就会恢复为普通输入。

## Everything 文件与文件夹搜索

Asterun 默认已经可以搜索 Windows 程序来源；Everything 是一个**可选的文件与文件夹搜索扩展**。

<p align="center">
  <img src="assets/readme/settings-search-sources.webp" alt="Asterun 搜索来源设置" width="820">
</p>

### 开启方法

进入：

**设置 → 搜索来源 → 文件与文件夹 → Everything 文件与文件夹**

如果当前没有检测到可用的 Everything，页面会提供 **获取并启动 Everything**。Asterun 托管模式会获取兼容的稳定版本，并负责必要的校验、启动和状态维护。

Everything 正常运行后，Asterun 的搜索结果中就可以出现本地文件和文件夹。

### 如果你已经装了 Everything

Asterun 会区分**自己托管的 Everything**和**用户自行维护的 Everything**。如果系统里已经存在兼容实例，Asterun 的原则是不无条件接管用户已有安装。

页面状态会告诉你当前是：

- Everything 正在运行；
- 未检测到可用 Everything；
- 正在准备 / 下载 / 校验 / 连接；
- 检测到多个实例；
- 准备失败。

遇到状态不一致时，可以先点 **重新检测**。

### “显示 Everything 托盘图标”是什么

这个选项只控制 **Asterun 托管的 Everything** 是否显示自己的托盘图标。

它和 Asterun 自己的 **显示系统托盘图标** 是两件不同的事：

- Asterun 托盘图标：Asterun 自己的后台入口；
- Everything 托盘图标：Everything 自己的后台入口。

如果你只想让 Everything 默默为 Asterun 提供搜索，可以关闭 Everything 托盘图标。

## 自定义快捷项

Asterun 不只是搜索系统里已经存在的程序。你还可以自己创建“快捷词 → 动作”。

按 **Alt + S** 打开 **Asterun 快捷项管理**，或者从托盘菜单进入快捷项管理，然后选择 **新建快捷项**。

### 最简单的用法

例如你经常打开一个工具：

- 快捷词：`vpn`
- 名称：`v2rayN`
- 目标：选择对应的 `.exe`

以后呼出 Asterun，输入 `vpn` 就能直接找到它。

**多个快捷词可以用逗号分隔，第一个优先级最高。** 例如：

`ts, team, teamspeak`

### 支持的目标类型

快捷项编辑器支持：

- **自动识别**
- **应用程序**
- **网址**
- **文件夹**
- **命令行**

简单场景建议保持“自动识别”，只有在识别不符合预期时再手动指定类型。

### 固定参数、工作目录和管理员运行

高级快捷项可以继续设置：

- **固定参数**
- **工作目录**
- **以管理员身份运行**

工作目录留空时，Asterun 会自动使用目标所在目录。

### 运行时输入

“运行时输入”适合需要把临时文本交给程序、命令或网址的高级快捷项，支持：

- **不接受额外输入**
- **原样传递**
- **URL 编码（UTF-8）**

需要精确指定插入位置时，可以在目标、固定参数或工作目录中使用 `{input}`。对于应用程序 / 命令行，如果没有手动写 `{input}`，部分模式可以自动把运行时输入追加到固定参数。

这里最推荐的做法是：**先填写“测试输入”，再点“测试”确认实际效果，确认无误后保存。** 这样比直接猜命令行转义规则可靠得多。

## “发送到 Asterun”

进入：

**设置 → 常规 → Windows 与启动 → 添加到“发送到”菜单**

开启后，Windows 的“发送到”菜单中会出现 **Asterun**。

之后可以：

**右键程序 / 文件 → 发送到 → Asterun**

把选中的路径交给 Asterun 的快捷项创建流程。对于经常把便携程序加入 Asterun 的用户，这比先打开快捷项管理再浏览文件更快。

在 Windows 11 上，根据系统右键菜单样式，你可能需要先进入 **显示更多选项** 才能看到“发送到”。

### 这个入口为什么 Asterun 退出后还在

这是正常的。

“发送到 Asterun”属于一个**持久的 Windows Shell 集成**。它的意义就是即使 Asterun 当前没有显示启动器，也可以从资源管理器把文件交给 Asterun。

因此：

- 正常退出 Asterun：不会删除这个入口；
- 在设置中关闭“添加到‘发送到’菜单”：会撤销这个入口；
- 运行 `Uninstall.exe`：v1.0.3 会校验所有权后清理 Asterun 自己创建的 `Asterun.lnk`。

如果你启用了这类系统集成，不再使用 Asterun 时更推荐运行 `Uninstall.exe`，而不是直接删除整个文件夹。

## Modern Compact 与 Classic

Asterun 提供两套启动器外观，但底层使用同一套搜索、排序、快捷项和 Provider。

### Modern Compact

**现代紧凑**是当前默认样式，也是普通用户优先推荐的样式。

它更适合 Windows 10/11，结果层级更清楚，并直接展示数字快速执行提示。

<p align="center">
  <img src="assets/readme/modern-compact.webp" alt="Asterun Modern Compact" width="820">
</p>

### Classic

**经典模式（ALTRun 风格）**保留经典 ALTRun 的紧凑视觉和操作方向。

<p align="center">
  <img src="assets/readme/classic.webp" alt="Asterun Classic" width="520">
</p>

切换位置：

**设置 → 外观 → 启动器样式**

切换样式不会改变你的快捷项、搜索来源或使用记录。

## 设置页怎么用

Asterun 的设置分成 6 个页面：

### 常规

主要控制 Windows 和日常执行行为：

- 开机启动；
- 启动行为：静默启动 / 显示启动通知 / 显示启动器；
- 提示音；
- Asterun 系统托盘图标；
- “发送到 Asterun”；
- 拼音搜索；
- 数字键快速执行；
- 仅剩一个结果时立即执行；
- 多显示器和窗口位置。

“仅剩一个结果时立即执行”属于偏激进的效率设置。第一次使用建议保持关闭，等熟悉搜索行为后再决定是否开启。

### 快捷键

可以修改：

- 主呼出快捷键；
- 辅助呼出快捷键；
- 打开设置；
- 打开快捷项管理；
- 在文件管理器定位；
- 复制选中目标等动作。

如果热键冲突，优先来这里处理。

### 搜索来源

控制哪些 Windows 来源参与搜索：

- 开始菜单；
- Windows Apps；
- App Paths；
- PATH；
- Everything 文件与文件夹。

如果你只想把 Asterun 当程序启动器，可以完全不启用 Everything。

### 外观

可以切换：

- 经典模式（ALTRun 风格）；
- 现代紧凑；
- 简体中文 / English。

### 数据

这里适合维护和迁移：

- 查看并打开数据目录；
- 导入快捷项；
- 导出快捷项；
- 清除使用历史；
- 重新建立程序索引；
- 恢复默认设置。

### 关于

这里可以：

- 查看当前版本；
- 自动检查更新；
- 选择是否接收预发布版本；
- 手动检查更新；
- 打开 GitHub 项目页。

普通用户建议保持 **稳定版**，不要开启“接收预发布版本更新”，除非你明确想参与测试。

## 便携使用、更新与卸载

### Asterun 是便携应用

Asterun 不需要传统安装器。把 Release ZIP 解压后即可运行。

主要运行时数据位于：

```text
Asterun/
├─ Asterun.exe
├─ Update.exe
├─ Uninstall.exe
└─ data/
   ├─ settings.json
   ├─ commands.json
   ├─ usage.json
   └─ provider-cache.json
```

因此备份 Asterun 时，通常把整个目录一起备份即可。

### 不建议在压缩包里直接运行

请先完整解压到普通可写目录。Asterun 需要写入本地 `data/`，目录不可写时，设置、快捷项和使用记录可能无法正常保存。

### 更新

进入 **设置 → 关于**：

- **自动检查更新**：后台检查稳定更新；
- **接收预发布版本更新**：测试用户使用；
- **检查更新**：立即手动检查。

正式稳定版 Release 同时提供 x64、ARM64、SHA-256 校验文件和更新清单。

### 什么时候需要 Uninstall.exe

因为 Asterun 是便携应用，单纯没有开启任何外部集成时，删除文件夹就能移除主体文件。

但如果你开启过：

- 开机启动；
- “发送到 Asterun”；
- Asterun 托管的 Everything 相关系统状态；

更推荐运行 **Uninstall.exe**，让 Asterun 先清理自己创建的外部状态，再删除程序目录。

特别是“发送到 Asterun”属于程序目录之外的 Windows Shell 快捷方式；直接删除程序目录以后，已经不存在的 Asterun 无法再执行清理逻辑。

## 常见问题

### 1. Alt + Space 没反应

最常见原因是全局快捷键被其他软件占用。

检查：

**设置 → 快捷键 → 主呼出快捷键**

Asterun 检测到冲突时会提示，但会继续驻留，不会因为热键失败直接退出。

### 2. 搜索不到某个刚安装的程序

先尝试：

**设置 → 数据 → 重新建立程序索引**

如果目标本来是一个没有注册到 Windows 程序来源的便携程序，也可以直接创建自定义快捷项。

### 3. 搜索不到文件

文件 / 文件夹搜索依赖 Everything。

检查：

**设置 → 搜索来源 → Everything 文件与文件夹**

并确认页面状态显示 Everything 可用。

### 4. 为什么结果顺序会变化

这是正常的智能排序行为。Asterun 会结合搜索匹配和使用记录调整结果顺序。

如果想清空学习记录：

**设置 → 数据 → 清除使用历史**

### 5. 为什么按数字没有启动对应结果

开启智能数字键后，Asterun 会判断数字是：

- 搜索内容的一部分；
- 还是你想执行对应编号结果。

例如 `v2rayN` 中的 `2` 更可能被当成继续输入。这是为了减少误启动。

### 6. 为什么 Asterun 退出后“发送到 Asterun”仍然存在

因为这是持久 Shell 集成，正常退出不应该撤销它。

关闭：

**设置 → 常规 → 添加到“发送到”菜单**

或者不再使用软件时运行 `Uninstall.exe`。

### 7. 为什么托盘里有两个图标

可能分别是：

- Asterun；
- Everything。

如果不需要 Everything 自己显示托盘图标，可以在 **设置 → 搜索来源** 关闭 **显示 Everything 托盘图标**。

### 8. 设置或快捷项保存不了

确认 Asterun 所在目录可写。不要把它长期放在压缩包、只读目录或需要特殊权限的系统目录中。

---

## 推荐的新用户设置

如果你不想研究太多选项，可以先保持下面这套思路：

- 使用 **现代紧凑**；
- 保持 **Alt + Space**；
- 保持 **启用拼音搜索**；
- 保持 **数字键快速执行结果**；
- “仅剩一个结果时立即执行”先关闭；
- 需要文件搜索时再开启 Everything；
- 自动更新保持稳定通道；
- 有便携程序时，用快捷项或“发送到 Asterun”添加。

熟悉几天后，再按自己的工作流修改快捷键、窗口位置、动态快捷项和预发布更新。
